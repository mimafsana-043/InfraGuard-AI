
# InfraGuard AI

### Intelligent Infrastructure Inspection & Defect Analytics

InfraGuard AI is an advanced Deep Learning
project focused on automated infrastructure
defect detection, instance segmentation,
and intelligent defect analysis.

## Project Objectives

- Multi-class infrastructure defect detection
- Instance segmentation
- Defect morphology analysis
- Image quality assessment
- Uncertainty-aware predictions

## Dataset

Cracks in the Foundation (CiF)

Dataset:
https://huggingface.co/datasets/ibm-research/cif-dataset

## Technology Stack

- Python
- PyTorch
- Torchvision
- OpenCV
- Albumentations
- Gradio
